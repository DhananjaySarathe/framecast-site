Remote guests

Bring in guests from anywhere.

Guests join your show from a browser, with nothing to install. For guests outside your Wi-Fi, Framecast needs two things you own: a copy of its guest page on a web host, and a LiveKit Cloud project to carry the video. Both are free, and you set them up once.

    Download the guest page

    This is the page your guests open from the invite link. It holds no keys: each invite link carries its own short-lived pass after the #, and browsers never send that part to the web host.

  2. 2

    Put it online with Cloudflare Pages

    1. Sign in to the Cloudflare dashboard, or create a free account.
    2. Go to Workers & Pages and choose Create application › Get started › Drag and drop your files.
    3. Give the project a name, for example yourname-guests. It becomes part of the address.
    4. Drag framecast-guest-page.zip onto the upload area (the unzipped folder works too), then click Deploy site.
    5. Copy the address Cloudflare gives you, like https://yourname-guests.pages.dev/. You'll need it in step 4.

    Cloudflare sometimes renames these menus. If yours look different, look for the option to upload files directly to Pages. Any other host works too, as long as it serves the files over https: Netlify, GitHub Pages or your own server.

  3. 3

    Create a LiveKit Cloud project

    LiveKit is the open-source video system Framecast uses for guests, and LiveKit Cloud runs it for you. With your own project, the video goes through your account and nobody else's.

    1. Sign up at cloud.livekit.io (free plan) and create a project.
    2. In the project's settings, create an API key.
    3. Copy three things: the project URL (wss://…livekit.cloud), the API key (starts with API) and the API secret. The secret is shown only once, so keep this tab open until step 4 is done.

Good to know

          

            
After updating Framecast
Download the guest page again and upload it in Cloudflare (your project › Create a new deployment), so it matches the app.

            
A Cloudflare error, like 522
Open the project in Cloudflare, check the latest deployment finished, and check the address matches the one in your settings file.

            
Who sees what
The video goes through your LiveKit project, so LiveKit sees your IP address and your guests'. Guests don't see yours. Your keys stay in your Mac's Keychain.
